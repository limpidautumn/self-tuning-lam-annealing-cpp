Detailed Description

template<typename Derived>
class stlam::CopyNeighborProblem< Derived >

CRTP helper for problems that use copy-and-restore neighbors.

Derived must provide these public members:

  • using Solution = stlam::ScoredSolution<RawSolution>;
  • Solution RandomSolution(Rng&) const Returns a random initial candidate with cost set.
  • void RandomNeighbor(Solution&, Rng&) const Replaces the candidate with a random neighbor and updates cost.

RandomNeighbor may recompute cost from scratch or update it incrementally, but must leave solution and cost synchronized.

TuneAccept and Accept are inherited no-ops; override them in Derived to observe accepted moves. They must remain public.
