Detailed Description

Base interface for user-defined optimization problems.

Serves as a type constraint for SelfTuningLam. Derived classes must implement the following public interface:

  • using Solution = stlam::ScoredSolution<RawSolution>;: Problem-specific scored solution type.
  • Solution RandomSolution(Rng&) const: Returns a valid initial candidate with its cost correctly evaluated.
  • Token Propose(Solution&, Rng&) const: Mutates the solution in-place to generate a neighbor and returns an opaque undo token. Token is implementation-defined: it may be a saved solution, a move index, or any value that can undo the move.
  • void Reject(Solution&, Token&&) const: Restores the solution to its pre-Propose state using the token.
  • void Accept(Solution&, Token&&) const (optional): Consumes the token after an accepted move. Defaults to a no-op.
  • void TuneAccept(Solution&, Token&&) const (optional): Consumes the token during the temperature tuning. Defaults to a no-op.

Propose returns one token per call. It is passed to exactly one of Reject, Accept, or TuneAccept, and must not be used afterwards. RandomSolution must set cost; Propose and Reject must keep Solution::solution and Solution::cost synchronized.
