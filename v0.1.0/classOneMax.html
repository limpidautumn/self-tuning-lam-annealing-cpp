Detailed Description

OneMax problem using copy-neighbor moves.

OneMax problem using delta-neighbor moves.

Minimizes the negative number of set bits. RandomNeighbor recomputes the cost from scratch after each bit flip.

Minimizes the negative number of set bits. Each move flips one bit and updates the cost incrementally; the returned bit index is also the undo token.
