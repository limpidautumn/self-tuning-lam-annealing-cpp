Detailed Description

template<typename Derived>
class stlam::DeltaNeighborProblem< Derived >

CRTP helper for problems that use apply-and-undo neighbors.

Derived must provide these public members:

  • using Solution = stlam::ScoredSolution<RawSolution>;
  • Solution RandomSolution(Rng&) const Returns a random initial candidate with cost set.
  • T ApplyRandomMove(Solution&, Rng&) const Applies a random move, updates cost, and returns an undo token.
  • void UndoMove(Solution&, T&&) const Reverses the move using the token and restores cost.

ApplyRandomMove and UndoMove must leave solution and cost synchronized. The token was forwarded as an rvalue, so T may be move-only.

TuneAccept and Accept are inherited no-ops; override them in Derived to observe accepted moves. They must remain public.
