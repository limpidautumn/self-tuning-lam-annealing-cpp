Detailed Description

template<typename Problem>
class stlam::SelfTuningLam< Problem >

The Self-Tuning Lam annealing schedule.

Tunes the phase length, EMA rate, initial acceptance rate, and temperature schedule (Algorithms 3-6), then anneals while tracking the target Lam acceptance rate (Algorithm 7).
